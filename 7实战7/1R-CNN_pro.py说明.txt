# 上个版本改进
# 原理：
# Selective Search算法本身具有一定的随机性，但如果我们只运行一次，那么每次得到的候选区域是固定的。
# 在目标检测中，我们希望模型能够看到更多样的候选区域，这样有助于提高模型的泛化能力。
# 因此，我们可以通过运行多次Selective Search（或者使用不同的参数）来生成更多的候选区域，然后从中随机选择一部分用于训练。

# 具体步骤：
# 在预计算阶段，使用两种Selective Search模式（快速模式和质量模式）生成更多的候选区域。
# 对生成的候选区域进行去重（基于IOU）和筛选（面积、宽高比等）。
# 存储足够多的候选区域（比如4000个），在训练时每次随机选择2000个。
# 在验证和测试阶段，可以使用固定的候选区域（例如前2000个）以确保可重复性。

一、Selective Search 有两种主要模式，它们产生候选区域的方式不同
# 快速模式 (Fast)
ss.switchToSelectiveSearchFast()
# 特点：速度快，区域数量相对较少，区域较规则

# 质量模式 (Quality)
ss.switchToSelectiveSearchQuality()
# 特点：速度慢，区域数量多，区域更精细，能发现更复杂的形状

三、为什么需要多样性？
目标检测的训练过程
训练样本 = 图像 + 候选区域 + 标签

问题：
如果候选区域不变 → 模型只能学习固定的区域特征
如果候选区域多样 → 模型能学习更多样化的特征表示

四、
几何视角：
原始区域：      增强后区域：
[100, 100, 200, 200]  →  [95, 95, 205, 205]  # 放大
                 →  [105, 105, 195, 195]  # 缩小
                 →  [110, 100, 210, 200]  # 水平移动

特征学习视角：
模型看到的正样本：
- 原始ROI：车辆的一部分（车头）
- 增强ROI1：车辆的更大范围（车头+引擎盖）
- 增强ROI2：车辆的更小范围（仅车牌区域）
- 增强ROI3：偏移的位置（车辆左侧）

→ 模型学会识别车辆的不同部分和不同尺度

五、效果
# 实验：不同ROI策略对mAP的影响

# 方案A：固定ROI（原始方法）
epoch 1: AP = 0.45
epoch 10: AP = 0.58
epoch 20: AP = 0.61  # 收敛较快，但上限较低

# 方案B：随机选择ROI（多样性）
epoch 1: AP = 0.42
epoch 10: AP = 0.55
epoch 20: AP = 0.65  # 收敛稍慢，但上限更高

# 方案C：多样性 + 增强（最佳）
epoch 1: AP = 0.43
epoch 10: AP = 0.62
epoch 20: AP = 0.69  # 收敛快且上限高

六、原理总结
核心思想：通过多种方式生成候选区域，让模型在训练过程中看到：

不同尺度的区域（快速模式通常产生较大的区域，质量模式产生更精细的区域）
不同形状的区域（不同算法对同一物体的分割方式不同）
轻微变化的位置（通过数据增强）
不同质量的建议（有些区域可能刚好包含完整物体，有些可能只包含部分）
